# Quicker Link

[![Android CI](https://github.com/shuimowang/QuickerLink/actions/workflows/android.yml/badge.svg)](https://github.com/shuimowang/QuickerLink/actions/workflows/android.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-146B52.svg)](LICENSE)
[![Android 10+](https://img.shields.io/badge/Android-10%2B-3DDC84.svg)](https://developer.android.com/)

Quicker Link 是一个非官方的开源 Android 客户端，通过局域网 `WSS` 直连电脑上的 [Quicker](https://getquicker.net/)。你可以在手机上触发常用动作、查看电脑当前屏幕，并在手机与电脑之间交换文本、通知和小文件。

> 本项目与 Quicker 官方及北京立迩合讯科技有限公司无隶属或授权关系。Quicker 是其权利人的产品和商标。

## 功能

- 通过 `WSS` 加密直连局域网中的 Quicker
- 自动发现同一局域网中的 Quicker，保留手动地址作为高级选项
- 扫描 Quicker Link 专用配对二维码
- 运行配套 Quicker 动作，自动读取当前 WSS 设置并离线生成配对二维码
- 扫码连接后自动同步 Quicker 新面板中的全局与通用动作、分组与顺序
- 以每行 4 至 6 个的高密度图标网格浏览动作，通过顶部横向分组导航切换，并搜索当前分组的名称、分组或 ID
- 连接验证码认证，异常断线自动重连
- 手工动作可编辑、删除；同步动作可设置参数和执行前确认
- 从同步或手工动作菜单终止仍在 Quicker 中运行的动作；手工动作可使用名称或 ID
- 通过动作名称或 ID 执行动作，并传入文本参数
- 将 Quicker 动作右键菜单同步为可自由输入的参数快捷选项
- 点击后只把动作派发给 Quicker，不等待持续运行类动作结束
- 一次性获取电脑当前屏幕；显式进入点击模式后可映射左键点击，并以约 1.2 秒间隔串行刷新快照
- 读取电脑剪贴板文本，或把手机文本写入电脑剪贴板
- 可选的前台双向剪贴板短文本同步，默认关闭并过滤 Android 标记的敏感剪贴板
- 在手机与电脑之间双向传输不超过 64 MiB 的文件，显示进度并支持取消
- 电脑端默认遵循 Windows 实际“下载”位置，并可在配对窗口选择手机文件的保存目录
- 允许电脑本机的 Quicker 动作主动向已连接手机发送文本、系统通知或文件邀请
- 经二次确认后让电脑关机、进入睡眠，或重启 Quicker
- 动作发送成功提示可继续输入文本，并可选择是否追加回车，默认追加
- 接收 Quicker 发来的 `copy` 消息并写入手机剪贴板
- “后台接收与连接”默认开启，可主动关闭；通过 Android 前台服务在切换应用或锁屏后保持局域网会话，并接收电脑文本、系统通知和文件邀请
- 使用 Android Keystore 加密保存连接验证码
- 无账号、无云端、无广告、无统计 SDK
- 在“关于”页面手动检查更新，按需下载校验并打开 Android 系统安装器；不进行后台或自动检查

## 使用

### 1. 配置 Quicker

在 Quicker 中打开：

```text
设置 -> 手机 APP / WebSocket 设置
```

开启 WebSocket 服务和安全连接 `WSS`，并确认 Windows 防火墙允许 Quicker 使用该端口。强烈建议设置连接验证码：空验证码可以连接，但同一局域网内的其他设备无需验证码即可尝试使用 Quicker WebSocket 能力，只适合你完全信任的网络。配套动作只能读取当前设置，不能替 Quicker 创建、修改或应用验证码；修改设置后请先在 Quicker 中保存，再重新运行配套动作生成二维码。

先从 Quicker 动作库安装配套的 [`Quicker Link`](https://getquicker.net/Sharedaction?code=b02b2732-f087-4e45-416d-08deee3e76ba) 动作。它不会替你修改端口或重新生成验证码，并为已配对 App 提供动作目录和用户主动发起的屏幕、剪贴板及小文件操作。Android 客户端源码完整保留在本仓库；配套 Quicker 动作独立发布，其维护源码不随本仓库分发。

### 2. 连接手机

手机与电脑连接到同一个可互访的局域网。首选方式是在电脑上运行 `Quicker Link` 动作，然后在 App 的连接页面点击“扫描配对码”。如果电脑有多个局域网地址，先在二维码窗口中选择与手机同网段的地址。二维码在本机内存中生成，不会上传；若已设置验证码，二维码也会包含它，因此不要截图或分享。新安装默认会使用 Android Keystore 加密保存验证码；每次打开 App 后首次连接会自动同步全局与通用动作并确认配套能力，同一电脑短线重连不会重复同步。可以在连接前关闭“加密保存并自动连接”。

也可以在“连接”页面输入连接验证码（可以留空）后点击“自动查找并连接”。自定义端口或无法发现时，可以展开“高级设置”手动填写 IPv4，或打开[网页版配对码生成器](https://shuimowang.github.io/QuickerLink/pairing.html)生成专用二维码。网页版只在浏览器本地处理输入且禁止外联；离线使用时请下载完整的 [`tools`](tools) 目录，并打开其中的 `pairing.html`。Quicker 会员中心“推送到电脑”页面的二维码属于云推送服务，不包含局域网 WSS 配置，不能用于本项目配对。

### 3. 同步与添加动作

扫码连接成功后，App 会通过配套动作读取 Quicker 新面板中的全局与通用动作，只同步动作 ID、名称、图标、来源、分组、面板顺序和动作右键菜单中的快捷参数；不会读取动作源码、动作内部变量或具体应用场景动作。配对动作本身不会出现在同步结果中。大型面板接近目录安全上限时，会优先保留动作映射，部分内联图标或快捷参数可能省略。以后可以在“动作”页面点击“刷新面板动作”手动更新。

再次同步会更新重命名、来源、分组和快捷参数变化，并移除已经不在全局与通用新面板中的同步项。同步项的名称、目标和快捷参数由 Quicker 管理，手机端仍可自由输入当前参数、从快捷选项中选择参数，并设置“执行前确认”。同步项菜单还可终止该动作当前的运行实例。同步项不提供单独删除；请在 Quicker 面板中移除后刷新。原有手工快捷项会保留；动作页通过横向标签切换 Quicker 分组，并在当前分组内按名称、分组或动作 ID 搜索。

如果电脑尚未安装配套动作或动作版本过旧，App 会显示“打开动作网页”入口，由用户前往 Quicker 动作网页完成安装或更新；其他同步失败会保留实际错误信息供排查。

也可以点击“添加动作”继续创建手工快捷项，填写 Quicker 动作名称或 ID。动作参数会作为 Quicker 的内置字符串参数传入，组合动作中可通过 `{quicker_in_param}` 使用。

如果 Quicker 中存在同名动作，请使用动作 ID，避免目标不明确。

建议对关机、删除文件等高风险动作开启“执行前确认”。

### 4. 使用传输工具

连接成功后打开底部“传输”页面：

- “当前屏幕”初次由用户主动获取，不进行视频录制；全屏预览切到点击模式后会保留该模式，并以约 1.2 秒间隔串行请求新快照。点击仍只映射当前有效快照中的一次左键操作，页面隐藏、断线或退出预览后不会继续刷新。
- “文本”统一放在传输页，可以读取电脑剪贴板、清空编辑框、写入电脑剪贴板或粘贴到电脑当前窗口。
- “发送文件”由 Android 系统文件选择器选取一个文件。电脑默认保存到 Windows 实际“下载 / Quicker Link”，也可在 Quicker Link 配对窗口中改为本机选择的目录。
- “接收文件”会在电脑上打开系统文件选择窗口，用户确认后才传到手机的“下载 / Quicker Link”。
- “电脑控制”只提供睡眠、关机和重启 Quicker 三个固定操作，手机每次执行前都会再次确认。

连接页的“前台剪贴板同步”默认关闭。开启后，只有 App 界面可见、连接已认证且 v8 配套能力确认完成时，才会双向同步符合大小限制的短文本；退到后台会立即停止监听和轮询。Android 10 及以上限制普通 App 在后台读取剪贴板，前台服务也不能绕过该系统边界；Android 13 及以上标记为敏感的剪贴板也不会自动发送。该功能不替代传输页中的手动读取和写入。

文件本体经过当前局域网 `WSS` 连接，以 64 KiB 分块传输，单个文件上限为 64 MiB。这个上限用于约束 Base64 文本分块经过 Quicker 动作逐次往返的耗时和暂存空间，并非 WebSocket 本身的 8 MiB 限制。双方都先写入临时文件并校验完整 SHA-256，再发布到最终位置；分块阶段可以取消，进入最终保存后会短暂锁定取消。若保存确认响应恰好丢失，App 会提供“重新确认”，使用同一传输标识查询原结果，不会重复落盘。异常遗留的临时文件会自动清理。这仍是面向动作配套使用的小文件通道，不替代专业的大文件传输工具。

### 5. 从电脑主动发送

电脑本机的 Quicker 动作可以带参数运行 `Quicker Link`，把内容发送给当前已认证的手机：

```text
sendText:来自电脑的文本
sendNotification:计时结束|休息一下
sendFile:D:\Downloads\report.pdf
```

`sendText:`、`sendNotification:` 和 `sendFile:` 都只是调用类型标识，不会作为内容发送到手机。文本取冒号后的正文；通知把冒号后的内容按第一个 `|` 拆成标题和正文；文件则读取冒号后的电脑本机路径，并向手机发送该路径对应的实际文件。手机只显示文件名和大小，由用户选择接收或拒绝，不会显示完整电脑路径。文本通常会复制到手机剪贴板并进入传输编辑区；若厂商系统在后台拦截剪贴板写入，正文仍会保留在 App 中。通知需要 Android 通知权限。参数调用只接受电脑本机自动化，不允许已连接手机反向提交电脑文件路径。文本最多 16,000 个字符，文件继续受 64 MiB 上限约束。“后台接收与连接”默认开启，因此正常切换应用或锁屏不会停止接收；用户主动关闭该开关后，App 退到后台会断开。

手机写入电脑剪贴板时，配套动作的独立文本历史默认关闭。只有电脑端用户在配对窗口明确开启“记录文本”后，正文才会保存在电脑本机，最多 100 条且历史文件不超过 1 MiB；该窗口也提供查看和清空入口。普通连接记录只保留摘要，不保存正文。

## 安装预览版

`v0.5.0-alpha.3` 是使用项目专用 Release 密钥签名的早期 prerelease APK，用于测试，不代表已达到稳定生产版质量。GitHub Release 不会发布调试签名或未签名 APK。

如需首次安装，请从 [Releases](https://github.com/shuimowang/QuickerLink/releases) 同时下载 `quicker-link-v0.5.0-alpha.3-release.apk` 和同名 `.sha256` 文件。首次安装时，Android 可能要求允许安装来自浏览器或文件管理器的应用。

安装前计算下载文件的 SHA-256，并与 `.sha256` 文件中的 64 位十六进制值逐字符比较：

```powershell
(Get-FileHash -Algorithm SHA256 -LiteralPath ".\quicker-link-v0.5.0-alpha.3-release.apk").Hash.ToLowerInvariant()
```

```bash
sha256sum --check quicker-link-v0.5.0-alpha.3-release.apk.sha256
```

校验和只能确认下载内容与发布的字节一致；请仍然仅从项目的 GitHub Release 页获取首个可信版本。

后续版本可在 App 的“关于”页面先点“手动检查更新”，确认版本后再点“下载并安装”。检查时优先读取项目 GitHub Pages 上由发布流程生成的受限更新索引；仅当该索引不可用时，才回退查询一次 GitHub Releases 公共 API。App 会下载 APK 与对应校验文件，并核对 SHA-256、包名、版本和签名证书；全部通过后才打开 Android 系统安装器。Android 最后仍会显示安装确认，首次使用此入口时还可能要求允许 Quicker Link 安装未知应用。检查、下载和安装都不会自动开始。

“后台接收与连接”在新安装以及从未明确关闭过该功能的安装中默认开启，也可以在连接页主动关闭。开启时，Android 前台服务会在正常锁屏、切换应用或 Activity 重建后继续保持 WSS 会话和自动重连，常驻通知中可直接停止后台连接。Android 13 及以上的通知权限只决定电脑通知和提示能否显示；拒绝该权限不会关闭后台 WSS 服务。电脑文本会优先写入手机剪贴板，即使后台写入被系统拦截也会保留在 App 中；文件邀请同样会保留，等待用户打开 App 确认。该设置不会开机自启，若服务被主动停止、强制停止 App 或进程被系统结束，则不保证电脑下行命令仍能即时处理。剪贴板自动同步无论此开关是否开启，都只在 App 界面可见时运行。

## 网络与安全

- 仅支持局域网内经过证书和主机名校验的 `WSS` 连接，并将目标限制为私有 IPv4。系统信任库仍是基础信任源；`lan.quicker.cc` 额外包含公开的 ISRG Root X2 根证书，以兼容缺少该根的设备。这不是服务器叶证书固定，也不会信任任意证书。
- App 不提供明文 `WS` 降级选项。
- WSS 连接和发现显式直连局域网目标，不经过 HTTP 代理；项目不提供系统级代理、VPN 或 Clash 配置功能。
- 自动发现带有候选、并发和超时上限；探测阶段不发送验证码，结果不明确时要求改用扫码或手动地址。
- 专用配对二维码包含连接地址，并在已设置时包含验证码；应按连接凭据保护，不要截图或分享。
- App 兼容 Quicker 的空验证码 WSS 模式，但会在连接页持续提示其风险并优先推荐验证码。App 中填写了验证码时会忽略无验证码握手，只等待与本次验证码请求匹配的认证响应，不会静默降级；更改验证码后应重新生成配对码。
- 配套 Quicker 动作不连接第三方服务；它在电脑本机生成配对信息、返回全局与通用动作目录，响应已配对 App 明确发起的动作终止、屏幕快照与点击、剪贴板、小文件和固定电脑控制请求，并允许电脑本机自动化向已认证手机发送文本、通知或文件邀请。
- 手机不能浏览电脑目录，也不能提交任意电脑路径。“接收文件”必须由电脑端用户通过系统文件选择窗口确认；手机文件只写入电脑端本机选择并保存的接收目录。
- 点击模式使用低频串行快照刷新，不是视频流；每次左键点击仍绑定一个当前有效快照，不提供拖动、键盘输入或通用远程控制。
- 电脑控制只接受睡眠、关机和重启 Quicker 三个内置命令，App 每次执行前都会二次确认，不接受任意命令行。
- 屏幕、剪贴板和文件数据只经过当前已认证的局域网 `WSS` 会话，不会上传到本项目或其他云端服务。
- 文件使用 64 KiB 分块、分块及完整 SHA-256 校验和 `.part` 临时文件；单文件上限 64 MiB，同一时间只执行一个手机端传输任务。
- 动作图标只接受 Quicker 本地渲染的 PNG 数据或 `files.getquicker.net` 的受限 HTTPS 图片地址；App 不加载动作提供的任意第三方图标域名。
- “只同步全局与通用动作”限制的是 App 获取和展示的目录，不是 Quicker WebSocket 的权限边界；已认证客户端若已知其他动作 ID，Quicker 本身仍可能允许执行。
- 本项目不会禁用 TLS 证书或主机名校验。
- 短信监控/验证码转发与手机系统级代理目前均未实现。本版不申请短信读取或接收权限，也不声明或使用 `VpnService`，不会修改手机系统代理。
- 请勿将 Quicker WebSocket 端口直接暴露到公网。

更多说明见 [隐私说明](PRIVACY.md)、[安全策略](SECURITY.md) 和 [连接实现边界](docs/PROTOCOL.md)。

## 构建

要求：

- Android 10 或更高版本
- JDK 17
- Android SDK Platform 37.0
- Android SDK Build Tools 36.0.0

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease
```

Debug APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

`assembleRelease` 在本地和常规 CI 中只用于确认 Release 变体可以编译，生成的未签名 APK 不得分发。常规 CI 只上传明确标记的 Debug 测试产物；`v*` tag 工作流会从 GitHub Secrets 临时注入专用密钥，仅在签名验证通过后创建 prerelease。维护者流程见 [发布指南](docs/RELEASING.md)。

## 项目状态

当前为专用 Release 密钥签名的早期 prerelease，聚焦局域网内稳定触发动作和受控的小规模数据交换。可选前台服务能在正常锁屏或切换应用时保持连接，但不承诺开机自启、进程被系统结束后的持续在线或后台剪贴板同步。暂不支持公网中转、视频级连续屏幕、完整远程桌面、文件夹或大文件传输、图片直接粘贴、断点续传、短信监控转发或手机系统级代理；面板动作目录只在首次确认配套能力或用户手动刷新时同步。

欢迎阅读 [贡献指南](CONTRIBUTING.md) 并提交 Issue 或 Pull Request。

## 设计参考

局域网发现、设备交互和传输状态机的设计调研参考了 LANChat、drift、[Websocket.Client](https://github.com/Marfusios/websocket-client) 与 [Sefirah](https://github.com/shrimqy/Sefirah)。其中 LANChat 用于比较 Android、Windows、设备列表和文件交互，drift 用于比较 WebSocket 二进制分块和临时文件状态，Websocket.Client 用于比较发送队列与重连，Sefirah 只用于比较配对、前台服务和跨端 UI；Sefirah 当前核心传输是 TCP/UDP Socket，并非 WebSocket。

Quicker Link 没有复制这些项目的源码，也没有引入它们作为依赖。相关项目各自遵循其仓库许可证；本项目实现仍以 Quicker 官方 `WSS` 服务和自身严格协议边界为准。
